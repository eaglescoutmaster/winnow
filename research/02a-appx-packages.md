# 02a - Preinstalled / provisioned Appx packages commonly treated as bloat

Research date: 2026-11-23. Targets: Windows 10 22H2 (19045), Windows 11 23H2 (22631), 24H2 (26100), 25H2 (26200). Research only; no code copied from any tool.

Machine-readable copy: `research/raw/appx-candidates.json` (68 entries).

## How to read this

- **Package** is the `Name` shown by `Get-AppxPackage` (package names are case-insensitive; source spelling differences are noted).
- **Store id** was accepted only when the Microsoft Store catalog (the service behind `apps.microsoft.com/detail/<id>`) returned that id with a matching package family name on 2026-11-23. Otherwise it is empty (null in JSON).
- **Builds** is `minBuild-maxBuild` restricted to what a source supports. `?` means not confirmed. Do not gate removal on these numbers; detect presence at runtime.
- **Returns** answers 'does Microsoft document this app coming back after a feature update': `no` means Microsoft documents that it stays removed once deprovisioned online; `unknown` means no Microsoft statement found.
- Tiers are suggestions made for this project, not taken from any source.

## Key findings

1. **Microsoft removed the per-version provisioned/installed/system app tables from Learn.** `overview-windows-apps` (ms.date 2026-03-28) now only tells you to run `Get-AppxProvisionedPackage -Online`; the old `provisioned-apps-windows-client-os` and `apps-in-windows-10` URLs redirect to it. There is therefore no current Microsoft table that says which build ships which app. Build ranges below come from narrower Microsoft statements plus secondary evidence.
2. **Reinstall after feature update:** Microsoft's 'Keep removed apps from returning during an update' page (ms.date 2026-11-20) says the reappearing-app problem affected Windows 10 1703/1709 and 'Windows 10, version 1803 has fixed this issue'. Removing a provisioned app online creates `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Appx\AppxAllUserStore\Deprovisioned\<PackageFamilyName>`, which tells Windows not to reinstall it. The page's package table is still the 1709 list, and it says the mechanism 'only applies to first-party apps that shipped with Windows 10'. Note: removing online only affects new users; the signed-in user keeps the app until it is also removed per-user.
3. **25H2 policy list (primary source for Windows 11):** the `RemoveDefaultMicrosoftStorePackages` policy (Enterprise/Education only, not Pro/Home) has 25 fixed entries. The Learn CSP page and the support article give the ids; the package family names were read from the Microsoft-shipped `AppxPackageManager.admx`. The CSP page labels applicability 'Windows Insider Preview [11.0.26100]'; the IT Pro blog says 25H2 Enterprise/Education. The ADMX also has a `DynamicRemovalList` multi-text value for arbitrary family names.
4. Policy entries deliberately **left out of this bloat list** (core utilities / default handlers): Microsoft.Windows.Photos, Microsoft.Paint, Microsoft.ScreenSketch, Microsoft.WindowsCalculator, Microsoft.WindowsNotepad, Microsoft.WindowsTerminal. Also excluded: Microsoft.WindowsStore, Microsoft.DesktopAppInstaller, Microsoft.StorePurchaseApp, Microsoft.HEVCVideoExtension.

## Conflicts between sources

- **Policy default vs. tool risk rating:** Microsoft's 25H2 policy example removes `Microsoft.Xbox.TCUI`, `Microsoft.XboxIdentityProvider` and `Microsoft.XboxSpeechToTextOverlay` by default; Raphire rates removing all three 'unsafe'. Tiered `aggressive` here.
- **Get Help:** Raphire 'unsafe', winutil plain removable. Tiered `moderate`.
- **Instagram name:** Store catalog says `Facebook.InstagramBeta`; Raphire says `Facebook.Instagram`.
- **LinkedIn name:** Store catalog and W4RH4WK say `7EE7776C.LinkedInforWindows`; Raphire lists `LinkedInforWindows`.
- **Case only:** Store catalog `Microsoft.OutlookforWindows` / `Microsoft.XboxSpeechtoTextOverlay` vs. ADMX `Microsoft.OutlookForWindows` / `Microsoft.XboxSpeechToTextOverlay`. ADMX spelling used.
- **Teams:** VDOT points both `MicrosoftTeams` and `MSTeams` at Store id XP8BT8DW290MPQ; the catalog maps that id only to `MSTeams_8wekyb3d8bbwe`. No Store id recorded for either (XP id is 14 characters).
- **Policy applicability:** CSP page says 'Windows Insider Preview [11.0.26100]'; support article and IT Pro blog say 25H2 Enterprise/Education; a search snippet claims later extension to 24H2 (not verified on a Microsoft page).
- **Dev Home:** winutil/VDOT call 9N8MHTPHNGVV 'Dev Home'; the Store catalog now titles it 'Windows Advanced Settings' for the same package family.
- **winutil Store ids** all matched the catalog. winutil has no id for Solitaire, Xbox TCUI and Speech-to-Text; the catalog supplied 9WZDNCRFHWD2, 9NKNC0LD5NN6, 9P086NHDNB9W.
